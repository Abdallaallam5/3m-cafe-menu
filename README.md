# 3M cafe — Immersive Digital Menu (ليالي بيروت)

**الموقع المنشور:** https://3m-cafe-menu.vercel.app/ — أي push على `main` بيتنشر تلقائيًا على Vercel.

منيو رقمي تفاعلي لـ **3M cafe** مبني من ملف الـ PDF الأصلي (5 صفحات) — موقع حقيقي بـ HTML/CSS/JS بدون أي مكتبات خارجية، يعمل كـ PWA وبيشتغل أوفلاين بعد أول زيارة.

## المميزات
- 15 قسم و132 صنف منقولين من الـ PDF بنفس الكتابة والأسعار (`data/menu.json`).
- تصميم RTL، ألوان البيج والبني والذهبي، اللوجو الأصلي، وصور الأقسام مقصوصة من المنيو نفسه (مفيش صور عشوائية).
- أنيميشن خفيف وواقعي: بخار القهوة (SVG)، سعف نخيل بيتحرك مع النسيم، حبوب بن طايرة، إضاءة شمس دافية، Parallax، ظهور تدريجي للأقسام والكروت، لمعة ذهبية عند الـ hover.
- احترام `prefers-reduced-motion`.
- شريط أقسام ثابت مع تتبّع القسم الحالي، بحث عربي ذكي (بيتجاهل الهمزات/التاء المربوطة/الياء)، زر الرجوع للأقسام، زر الرجوع لأعلى، شاشة تحميل.
- PWA: `manifest.json` + Service Worker (cache-first للملفات الثابتة، network-first للصفحة، stale-while-revalidate للمنيو)، مؤشر "أنت غير متصل"، رسالة "نسخة جديدة متاحة" عند نشر تحديث، زر التثبيت على الشاشة الرئيسية.

> **مهم:** أول مرة العميل يمسح الـ QR لازم يكون معاه إنترنت. بعد ما الموقع يتحمّل مرة واحدة، المنيو كله (النصوص والصور والخطوط) بيتخزن على الموبايل ويفتح حتى بدون إنترنت.

## هيكل المشروع
```
index.template.html   ← قالب الصفحة (عدّل هنا)
sw.template.js        ← قالب الـ Service Worker
build.py              ← يولّد index.html و sw.js (قائمة الكاش + رقم النسخة)
index.html, sw.js     ← ملفات ناتجة — لا تعدّلها يدويًا
css/styles.css
js/app.js
data/menu.json        ← الأصناف والأسعار
manifest.json
vercel.json           ← هيدرز الكاش للنشر على Vercel
assets/img, assets/icons, assets/fonts
src/frond-symbol.svgfrag ← رسمة سعفة النخيل (SVG)
tools/make_qr.py      ← يولّد QR PNG + بوستر A4 PDF من رابط الموقع
```

## تعديل الأسعار أو الأصناف
1. عدّل `data/menu.json` (كل صنف: `"name"` و `"price"`).
2. شغّل: `python3 build.py` — بيحدّث رقم نسخة الكاش تلقائيًا.
3. انشر من جديد. العملاء هيظهرلهم زر «تحديث» أو هيشوفوا الأسعار الجديدة في الزيارة اللي بعدها.

## التشغيل محليًا
```bash
python3 build.py
python3 -m http.server 8080
# افتح http://localhost:8080
```

## النشر (Vercel — مجاني)
**من GitHub:** ارفع المجلد على repo → في Vercel: Add New → Project → Import → Framework: *Other*، بدون Build Command، Output Directory: `.` → Deploy.

**أو من الـ CLI:**
```bash
npm i -g vercel
vercel --prod
```
بعدها اربط دومين لو حابب (مثلاً `menu.3mcafe.com`) من Project → Settings → Domains.

يشتغل كمان على Netlify / GitHub Pages / Cloudflare Pages لأنه موقع ثابت بالكامل (لازم HTTPS عشان الـ Service Worker).

## توليد الـ QR والبوستر
بعد ما يبقى عندك الرابط النهائي:
```bash
pip install qrcode reportlab pillow
python3 tools/make_qr.py https://YOUR-FINAL-URL
```
بيطلع:
- `qr/3m-cafe-menu-qr.png` (2400×2400، تصحيح أخطاء عالي H وهامش أبيض واسع)
- `qr/3m-cafe-menu-poster-A4.pdf` (بوستر جاهز للطباعة)

استخدم الرابط النهائي الثابت (الدومين) — لو الرابط اتغير لازم تطبع QR جديد.

## نقاط تحتاج مراجعة يدوية من المنيو الأصلي
| القسم | الملاحظة |
|---|---|
| سموزي | «سموزي بطيخ» مكتوب مرتين بسعرين مختلفين: **70** و**60**. الاتنين معروضين زي الـ PDF — احذف واحد بعد التأكد. |
| الشيشة | «لى طبى» — 10 — منقولة حرفيًا، الكلمة مش واضحة المعنى. |
| فرابيه | «فرابيه بستاشيو» — في الـ PDF الحروف مشوشة شوية (في الوافل والميلك شيك مكتوبة «بيستاشيو»). |
| عام | الـ PDF مفيهوش عملة؛ الأسعار معروضة أرقام فقط. |
| عام | كلمات زي «شيرى كميل»، «ميلك بلوبيرى»، «مانجا كيوى»، «ماى» منقولة بالألف المقصورة زي الأصل. |

الحقل `"review"` في `menu.json` بيعلّم الأصناف دي (مش بيظهر للعميل).
